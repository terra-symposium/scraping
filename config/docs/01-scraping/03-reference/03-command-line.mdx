Install the package in the consuming repository, then run an installed command with `pnpm exec`. Each command accepts `--help`.

|||[canvas-export]

## canvas-export

```sh
pnpm exec canvas-export --canvas-url=https://canvas.example.edu/dashboard
```

| Option                       | Required | Default                                         | Behavior                                                                                                              |
| ---------------------------- | -------- | ----------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| `--canvas-url=URL`           | Yes      | None                                            | Canvas dashboard, course, or other Canvas URL used to start the workflow.                                             |
| `--groups="Week 1,Week 2"`   | No       | All module groups                               | Comma-separated, case-insensitive title fragments. Any fragment may match. `--group` is an alias.                     |
| `--output=PATH`              | No       | `~/Downloads/canvas-export`                     | Directory for the manifest, log, module text, and downloaded files.                                                   |
| `--headed` / `--interactive` | No       | Headless                                        | Either flag shows Chromium. If saved state is not ready, allow visible sign-in and save state outside the repository. |
| `--storage-state=PATH`       | No       | OS-level Canvas workflow path                   | Use a specific Playwright storage-state file.                                                                         |
| `--all-courses`              | No       | Season/year or semester/term-number/year titles | Include every visible course instead of applying the default course-title filter.                                     |
| `--help` or `-h`             | No       | —                                               | Print usage and exit.                                                                                                 |

The command prints progress messages and a JSON summary containing output and manifest. A course URL is exported by itself. For a dashboard or course list, the default filter keeps titles that look like a named season and year, or a semester/term number and year. `--interactive` is an alias for `--headed`.

See [Canvas API behavior](/01-scraping/03-reference/01-canvas/#complete-export-behavior) for the output tree and failure handling.

## syllabus-fetch

```sh
pnpm exec syllabus-fetch --state=NSW --headed
```

| Option                 | Required | Default                                           | Behavior                                                                                      |
| ---------------------- | -------- | ------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| `--state=CODE`         | Yes      | None                                              | One of ACT, NSW, NT, QLD, SA, TAS, VIC, or WA.                                                |
| `--output=DIR`         | No       | `~/Downloads/terra-symposium-scraping/syllabuses` | Directory for the downloaded Word file.                                                       |
| `--file-name=NAME`     | No       | Browser-suggested filename                        | Override the saved basename.                                                                  |
| `--syllabus-name=NAME` | No       | English K–10 (2022) for NSW                       | Choose the syllabus displayed by the NSW custom picker.                                       |
| `--headed`             | No       | Headless                                          | Keep the browser visible. Also enables interactive sign-in unless overridden through the API. |
| `--interactive`        | No       | Disabled unless `--headed` is present             | Permit a visible browser if current state is not ready.                                       |
| `--storage-state=PATH` | No       | Per-jurisdiction OS-level path                    | Use a specific Playwright storage-state file.                                                 |
| `--timeout=MS`         | No       | 30000                                             | Set the download-control timeout; a positive value also sets the interactive-auth timeout.    |
| `--help` or `-h`       | No       | —                                                 | Print usage and exit.                                                                         |

`--headed` also permits interactive sign-in. With `--interactive` alone, the first attempt is headless; the helper opens a visible session only if the page is not ready. The command prints the `FetchedAustralianSyllabus` result as JSON.

|||[canvas-transcripts]

## canvas-transcripts

```sh
pnpm exec canvas-transcripts --input=/path/to/transcript-sources --output=/path/to/transcript-inventory --weeks=12
```

| Option                 | Required | Default                     | Behavior                                                                                   |
| ---------------------- | -------- | --------------------------- | ------------------------------------------------------------------------------------------ |
| `--input=DIR`          | Yes      | None                        | Local tree to scan recursively for transcript files.                                       |
| `--output=DIR`         | Yes      | None                        | Directory for weekly text files and `transcripts-manifest.json`. Keep separate from input. |
| `--weeks=N`            | No       | 12                          | Positive integer defining the expected week range and number of weekly output files.       |
| `--mapping=FILE.json`  | No       | No explicit source metadata | Path-to-metadata JSON for manual week assignment and provenance.                           |
| `--expected=FILE.json` | No       | No expected meeting list    | Expected-meetings JSON for source coverage reporting.                                      |
| `--help` or `-h`       | No       | —                           | Print usage and exit.                                                                      |

The input and output must resolve to different paths. This tool is offline: it reads `.txt`, `.vtt`, and `.srt` files, never opens a browser or contacts Canvas, Zoom, or Kaltura, and leaves source files unchanged.

The command prints a JSON summary with output path, transcript count, found/partial/missing weeks, missing expected meeting IDs, unresolved sources, read errors, and duplicate count. Each requested week receives a `Week-##.txt` file, including a diagnostic file for an empty week.

See [Transcript inventory](/01-scraping/02-guides/05-transcript-inventory/) for week inference, metadata and expected-meeting JSON, report statuses, and review guidance.
