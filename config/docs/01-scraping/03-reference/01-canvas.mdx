Import from `@terra-symposium/scraping/canvas` or the package root, `@terra-symposium/scraping`. The module uses Playwright `Page`, `APIRequestContext`, and `APIResponse` values.

## Exported types

| Type                   | Shape and purpose                                                                                                   |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------- |
| `CanvasItem`           | `title`, `url`, and `type`, where type is `file`, `page`, or `link`.                                                |
| `CanvasCourse`         | Display `title` and canonical course `url`.                                                                         |
| `CanvasGroup`          | Module `title` and its `items: CanvasItem[]`.                                                                       |
| `CanvasFile`           | Absolute local `path`, saved `name`, and optional sanitized `sourceUrl`.                                            |
| `ExportedGroup`        | `course`, module `title`, saved `files`, `textPath`, external `links`, combined page `text`, and per-item `errors`. |
| `CanvasExportManifest` | Sanitized `source`, literal mode `download`, selected course summaries, and all exported `groups`.                  |
| `CanvasScrapeResult`   | Absolute `output` directory, the `manifest`, and sanitized `logs`.                                                  |

## Choose the collection level

|||[Managed full export] `scrapeCanvas(options: CanvasScrapeOptions): Promise<CanvasScrapeResult>` owns authentication, collection, output files, and browser cleanup.

| Field | Type | Default and behavior |
| --- | --- | --- |
| `canvasUrl` | `string` | Required HTTP or HTTPS Canvas URL. A direct course URL exports that course; a dashboard or course list discovers courses. Credentials, query, and fragment are removed before the URL is stored. |
| `output` | `string` | `~/Downloads/canvas-export`. The resolved absolute directory receives the manifest, log, and course files. |
| `groupMatches` | `string[]` | All module groups. When supplied, a group is included if its title contains any case-insensitive fragment. |
| `storageStatePath` | `string` | OS-level Canvas workflow state file. Supply a path to select another Playwright state file. |
| `headed` | `boolean` | `false`. Show Chromium and keep the returned workflow in a visible browser. |
| `interactive` | `boolean` | Defaults to `headed`. If readiness fails, permit visible manual sign-in. A headless run closes its initial session, opens a visible one, saves state, then reopens and verifies a fresh headless session. |
| `includeAllCourses` | `boolean` | `false`. Keep all visible courses rather than applying the default semester, term, or season plus year title filter. |
| `createSession` | `(options: WorkflowSessionFactoryOptions) => Promise<WorkflowBrowserSession>` | Optional browser-session factory for a consumer-specific channel, executable, or persistent profile. The shared workflow owns and closes the returned session. |
| `log` | `(message: string, failure?: boolean) => void` | Optional progress callback. Receives `[canvas-export]` messages with sensitive URL parts removed. Progress goes to stdout and failures to stderr by default. |

The manifest includes the sanitized source URL, selected course titles and URLs, group summaries, and each `ExportedGroup` record. The `logs` array contains the sanitized progress and error lines written to `canvas-export.log`. |||

|||[Compose with lower-level functions] `scrapeCanvasCourse(options: ScrapeCanvasCourseOptions): Promise<ExportedGroup[]>` requires:

| Field          | Type                                           | Purpose                                                                               |
| -------------- | ---------------------------------------------- | ------------------------------------------------------------------------------------- |
| `page`         | Playwright `Page`                              | Authenticated page used to navigate the course and its module pages.                  |
| `request`      | `APIRequestContext`                            | Authenticated request context from the same browser context, used for file downloads. |
| `course`       | `CanvasCourse`                                 | Course title and URL.                                                                 |
| `output`       | `string`                                       | Base output directory.                                                                |
| `groupMatches` | `string[]`                                     | Optional case-insensitive module-title fragments; any fragment may match.             |
| `log`          | `(message: string, failure?: boolean) => void` | Optional progress/error callback.                                                     |

`scrapeCanvasGroup` accepts `{ page, request, course, group, output, log? }`. Its `page` and `request` must come from the same authenticated `BrowserContext`. `group` is a `CanvasGroup`. This helper processes one group's resources but does not launch, authenticate, or close a browser.

`scrapeCanvasCourse` navigates to the course's `/modules` route, discovers matching groups, and scrapes them sequentially. It returns an empty array when no groups match. Both lower-level functions preserve the caller's browser lifecycle. |||

# The default course-title filter recognizes a season followed by a four-digit year (or year before season), and semester/term followed by a one- or two-digit number and a four-digit year (or year before semester/term and number). A direct course URL is handled as one course without that title filter. A URL pointing into a course is normalized to its `/modules` page.

## Complete export behavior

The top-level exporter stores files under:

```text
<output>/
  manifest.json
  canvas-export.log
  <course-name>/
    <module-name>/
      <module-name>.txt
      <file-id>-<safe-file-name>
```

The default output directory is `~/Downloads/canvas-export`. Course and module folder names are Unicode-normalized lowercase slugs limited to 120 characters. Each module text file contains the title, sanitized Canvas page URL, and readable text for every Canvas page in that module. The group's `files` array includes this text file as well as downloaded attachments.

Page links discovered in a module group are read as text. Canvas course files listed directly in a group or linked from a captured Canvas page are downloaded through the authenticated request context. External links are recorded in the group's `links` array and are not fetched. Duplicate course-file URLs are downloaded once within a group.

A failed resource is recorded in the group's `errors` array and logged; later items continue. Top-level failures such as an invalid URL, failed authentication, or no matching courses throw an error. The exporter writes the sanitized log even after a top-level failure, and always closes its owned browser session.

The exporter saves session state outside the repository under the OS application-support workflow directory. Headless mode is the default. Set `headed` or `interactive` to permit visible sign-in; when `headed` is true, `interactive` defaults to true. The CLI maps `--headed` and its `--interactive` alias to visible and interactive behavior.

Canvas collection reads courses and module resources visible to the signed-in account. It does not fetch grades, submissions, rosters, or private messages. Review course rules and keep downloaded content and browser state private.
