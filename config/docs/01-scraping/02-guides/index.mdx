## Workflow foundations

Start with the two shared helpers before building a collection task. [Browser sessions and authentication](/01-scraping/02-guides/01-browser-sessions/) explains headed and headless runs, sign-in recovery, saved state, and cleanup. [Parallel work](/01-scraping/02-guides/02-parallel-work/) explains worker-count precedence, bounded queues, and cross-process slots.

## Shared ownership

These workflows write source material locally. The consuming application owns its service-specific account checks, content transformation, review, and publishing.
